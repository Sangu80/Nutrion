
# Nutrition Recommendation System – iLab Capstone Project 2024

This repository contains the capstone project submitted by Group 7 for the iLab Capstone Program 2024. The focus of this project is on developing a **Nutrition Recommendation System** that helps users get personalized food recommendations based on various parameters such as BMI, age, dietary preferences, and medical conditions.

## 🧠 Project Objective

To design and implement a machine learning-based system that recommends a balanced nutritional plan to individuals by analyzing their demographic and health data.

## 🚀 Features

- Calculates BMI and classifies nutritional needs
- Machine Learning models for food recommendations
- Data visualization and health insights
- Personalized meal planning
- Support for multiple health parameters (e.g., diabetes, hypertension)

## 🛠️ Technologies Used

- Python (Pandas, NumPy, Scikit-learn)
- Jupyter Notebook
- Matplotlib & Seaborn (for visualization)
- Machine Learning (Decision Trees, KNN, etc.)
- PDF/Document generation

## 📊 Dataset

The system uses a customized nutrition dataset comprising:
- Nutritional values of food items
- Demographic and health-related user data
- Food categories aligned with dietary guidelines

